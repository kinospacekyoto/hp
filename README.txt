KINO SPACE KYOTO — website source

Files
- index.html: page structure and content
- styles.css: all visual styles and responsive rules
- script.js: language switching, navigation and reservation form behavior
- assets/: property photographs used by the website
- ALL_CODE.txt: complete HTML, CSS and JavaScript in one text file

Upload
Upload index.html, styles.css, script.js and the assets folder together to the public root of your web server. Keep the filenames and folder structure unchanged.

Important
- The availability section embeds Google Calendar and requires an internet connection.
- The reservation form opens the visitor's email application.
- Review the public URL, privacy notice and legal information after moving to your own domain.
